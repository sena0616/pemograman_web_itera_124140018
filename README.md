## Pertemuan 3 — React Basics

Pertemuan 3 terdiri dari dua project React yang dibuat menggunakan Vite.

### 1. My React App — Praktikum

Project praktikum untuk mempelajari:
- Components dan Props
- State Management dan React Hooks
- React Router
- Custom Hooks
- Context API
- Unit Testing

[Lihat My React App](Sena_Permatasari_124140018_pertemuan3/my-react-app)

### 2. BookNest — Tugas

BookNest merupakan aplikasi manajemen koleksi buku pribadi menggunakan React.

Fitur aplikasi:
- Menambah, mengedit, dan menghapus buku
- Pencarian dan filter buku
- Statistik koleksi
- Penyimpanan menggunakan localStorage
- Navigasi dengan React Router
- Unit Testing (10 tests passed)

[Lihat BookNest](Sena_Permatasari_124140018_pertemuan3/BookNest)

## Cara Menjalankan

### Pertemuan 1 dan 2

1. Clone repository ini.
2. Buka folder pertemuan yang diinginkan.
3. Buka file `index.html` di browser.

### Pertemuan 3 — My React App

```bash
cd Sena_Permatasari_124140018_pertemuan3/my-react-app
npm install
npm run dev
```

### Pertemuan 3 — BookNest

```bash
cd Sena_Permatasari_124140018_pertemuan3/BookNest
npm install
npm run dev
```
